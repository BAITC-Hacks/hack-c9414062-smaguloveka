# Проверка ASR на казахском и шала-казахском (синтетические записи)

Модель: GigaAM-Multilingual large CTC, int8 ONNX, CPU (`app/pipeline/asr.py`). Нарезка по эталонным границам реплик из `samples/*.turns.json` (диаризация не участвует). Нормализация: нижний регистр, ё→е, без пунктуации. CER считается без пробелов.

Загрузка модели: 10.5 с; распознавание 172 с аудио за 112.3 с (RTF 0.654).
